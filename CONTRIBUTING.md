# Contributing

Thanks for helping improve the SNTL 84 Trade Directory prototype.

## Working principles
- Keep the first iteration simple and useful.
- Do not present demo data as real or verified business information.
- Keep secrets out of source control. Use local environment files.
- Prefer accessible controls, responsive layouts, and clear empty/error states.
- Make small changes with descriptive commit messages.

## Local workflow
1. Install Node.js LTS.
2. Run `npm install`.
3. Run `npm run dev` while developing.
4. Run `npm run lint` and `npm run build` before a pull request when possible.
5. Summarize what changed, how it was checked, and any known limitation.

## Proposed workflow stages
See [README.md](README.md#delivery-roadmap) for the staged product plan. Changes to database schema, sign-in, business verification, or payments should be discussed before implementation.
